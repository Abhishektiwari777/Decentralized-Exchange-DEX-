# Decentralized Exchange (DEX)

## 🧾 Project Description
A minimal Decentralized Exchange smart contract built with Solidity that enables users to add liquidity and swap ERC20 tokens in a trustless and peer-to-peer manner.

## 🌐 Project Vision
To democratize finance by enabling secure, permissionless token swaps without relying on centralized intermediaries.

## 🚀 Key Features
- Add liquidity for ERC20 tokens
- Perform 1:1 token swaps
- Simple and gas-efficient implementation
- Event logging for transparency

## 🔭 Future Scope
- Integrate with real-time price oracles (e.g., Chainlink)
- Dynamic pricing via Automated Market Maker (AMM) model
- Fee mechanism for liquidity providers
- Governance and token-based voting system
